**p4n4-api 0.4.0** serves p4n4-dashboard 1.5.0's Feed: each item's picture and link, in the reader's language. It also answers its errors so a browser on another origin can read them.

```bash
docker pull ghcr.io/raisga/p4n4-api:0.4.0     # amd64 and arm64
```

> **Trusted networks only.** The compose file publishes port 8000 on `127.0.0.1`. To reach the API from elsewhere, put it behind a TLS reverse proxy. Mounting the Docker socket (`docker-compose.docker.yml`) gives admins control of every container on the host.

## Highlights

- **Feed pictures:** `GET /api/v1/feed/{id}/image` relays an item's picture (an item with `"image": true`) from the project's feed, with the feed's token, for anyone signed in. It passes JPEG, PNG and WebP up to 8 MiB; anything else is `502 feed_failed`, and a missing picture is `404 feed_item_not_found`.
- **Feed links:** an item may carry a `link` (`label` and `url`), such as the project's own review page. One that isn't an `http(s)` URL is dropped, so the dashboard never opens it.
- **The reader's language:** `GET /api/v1/feed` and the feed's actions take `lang` (a language tag such as `es` or `en-US`) and pass it on, so a feed that speaks it answers in it.
- **500s a browser can read:** an unhandled error now answers from inside the API's middleware, so its `500` carries the CORS headers and `X-Request-ID`. A dashboard on another origin used to see a CORS error instead.
- **Stack status without the Docker probe:** `GET /api/v1/stacks[/{stack}]` and the assistant's project context only check that Docker access is on (`P4N4_API_DOCKER`), and report the daemon's or Compose's own failure as `503` with its reason, one call fewer per request. A missing Compose plugin is now a `503` too.

## Compatibility

- Built on **p4n4-lib 0.4.0** or later (the image installs `>=0.4.0,<0.5` from PyPI, so 0.4.2).
- Pairs with **p4n4-dashboard 1.5.0**, which shows the Feed's pictures and links and asks for its language. 1.3.0 and 1.4.0 keep working: they ignore the new fields.

## Upgrading from 0.3.0

- Nothing to migrate: the database is unchanged.
- A feed item's `link` that isn't `http(s)` no longer reaches clients.

## Limitations

- Not yet implemented: Prometheus metrics (`/metrics`). See the README's design-target notes.
